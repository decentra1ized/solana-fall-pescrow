A native Rust escrow written with Pinocchio 0.11: manual account validation, PDA derivation, zero-copy state, raw CPIs. Make was already there; this fork adds Take and Cancel, and proves them with LiteSVM tests.

Try it: escrow simulator

This runs in your browser. It applies the program's checks in the same order (signer, owner, stored maker and mints, PDA, token accounts, then the CPIs), so you can see where each attack gets stopped. It is a model of the program, not a devnet transaction.
